## Overview

Thesys is a versatile MIDI step sequencer with 32 steps, per-step velocity, pitch, chord, and 16 dedicated CC modulation lanes for driving synths and effects with intricate, evolving patterns.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes Thesys** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **32-Step Grid** | Programmable step sequencer with variable step resolution and ratchet |
| **CC Lanes** | 16 independent CC modulation lanes with per-step values and curves |
| **Chord Mode** | Assign chord voicings per step for complex harmonic progressions |
| **MIDI Capture** | Record incoming MIDI into the step grid for pattern extraction |
